Areas I'm focusing on

The parts of security I'm studying and practising right now.

network security

Networking foundations

How traffic flows, how protocols behave, and where a network is exposed. This is the base for everything else I learn.

What is this?

Networking is how computers and devices talk to each other, using things like IP addresses, routers, switches, DNS and protocols such as TCP/IP and HTTP. Security starts here because you can't defend traffic you don't understand. I practise this by building and testing networks in Cisco Packet Tracer.

blue team

SOC analysis

Reading alerts and logs, spotting suspicious activity, and learning how analysts triage incidents.

What is this?

A Security Operations Center (SOC) is the team that watches an organisation's systems for trouble. Analysts review alerts, decide which are real and which are false alarms, and escalate real incidents so they can be contained.

detection

Threat detection

Understanding what common attacks look like from the defender's side, and how to detect them.

What is this?

Threat detection means spotting signs of an attack, such as strange logins, unusual network traffic or suspicious programs. Defenders use logs, monitoring tools and detection rules to catch these early.

systems

Linux and administration

Getting comfortable on the command line, managing users and services, and hardening a system.

What is this?

Linux is the operating system behind most servers and many security tools. Administration means managing users and permissions, running services, installing updates and hardening a system so it is harder to break into.

cloud

Cloud security

Early exploration of how identity, storage and network controls work in cloud environments.

What is this?

Cloud security is protecting systems that run on platforms like AWS, Azure or Google Cloud. It focuses on who can access what (identity), how data is stored, and how cloud networks are configured.

automation

Python scripting

Using Python to automate small, repetitive tasks and to read and parse data.

What is this?

Python is a beginner-friendly programming language. In security it is used to automate repetitive jobs, such as reading through log files or pulling out useful details, so analysts save time.
